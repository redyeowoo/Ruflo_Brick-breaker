# Ruflo_Brick-breaker

Ruflo를 처음 사용해 Claude와 연결하고, 게임을 하나 만들어 보도록 시켜 본 프로젝트입니다.
결과물은 브라우저에서 바로 실행되는 벽돌깨기 게임입니다.

## 게임 설명

패들로 공을 튕겨 화면 위쪽의 벽돌을 모두 깨는 게임입니다.

### 규칙

- 벽돌은 6줄 × 10칸, 총 60개입니다.
- 벽돌 하나를 깨면 10점을 얻습니다.
- 목숨은 3개이며, 공이 화면 아래로 떨어지면 1개가 줄어듭니다.
- 목숨이 남아 있으면 공이 패들 위로 돌아와 다시 발사할 수 있습니다.
- 벽돌을 모두 깨면 승리, 목숨이 0이 되면 게임 오버입니다.

### 주요 기능

- 공이 패들의 어느 위치에 맞았는지에 따라 튕겨 나가는 각도가 달라집니다. 가운데에 맞으면 수직으로, 가장자리에 맞을수록 비스듬하게(최대 60도) 올라갑니다.
- 공의 속도는 항상 일정하게 유지되며, 공이 거의 수평으로만 움직이는 상황이 생기지 않도록 보정합니다.
- 공의 이동을 한 프레임 안에서 잘게 나누어 계산해, 공이 벽돌이나 패들을 뚫고 지나가지 않습니다.
- 화면 상단에 점수와 남은 목숨이 표시됩니다.
- 시작 대기, 승리, 게임 오버 상태에 맞는 안내 문구가 화면에 표시됩니다.
- 벽돌은 줄마다 다른 색으로 그려집니다.
- 브라우저 창 크기에 맞춰 게임 화면이 축소되어도 마우스 위치가 정확히 반영됩니다.

## 조작 방법

| 입력 | 동작 |
|------|------|
| 마우스 이동 | 패들 이동 |
| ← / → 방향키 | 패들 이동 |
| 스페이스 키 | 공 발사 / 승리·게임 오버 후 다시 시작 |

## 실행 방법

설치나 빌드 과정 없이 `src/breakout.html` 파일을 브라우저로 열면 됩니다.

- 파일 탐색기에서 `src/breakout.html`을 더블 클릭하거나
- 브라우저 창에 파일을 끌어다 놓거나
- 터미널에서 아래 명령을 실행합니다.

```bash
# Windows
start src/breakout.html

# macOS
open src/breakout.html

# Linux
xdg-open src/breakout.html
```
